# 

RPC

Protocol allowing programs to request services from other computers without understanding network details.

RISC-V

Open standard instruction set architecture based on reduced instruction set principles.

Patricia Trie

Efficient data structure for storing key-value pairs in blockchain state.

Merkle Tree

Cryptographic data structure enabling efficient data verification in blockchains.

ZK Proofs

Cryptographic methods allowing proof of knowledge without revealing actual information.

PoW

Consensus mechanism requiring computational work to validate transactions and create blocks.

Layer 2

Scaling solutions built on top of Layer 1 blockchains to improve throughput.

Layer 1

Base blockchain protocols providing security and consensus for decentralized networks.

Blockchain

Distributed ledger technology maintaining transaction records across multiple computers.

Rollups

Layer 2 solutions executing transactions off-chain while storing data on-chain.

ZK-STARK

Zero-knowledge proof system with transparent setup and quantum resistance.

Reentrancy Attack

Smart contract vulnerability where malicious code repeatedly calls back into the original contract.

ZK-SNARK

Zero-knowledge proof system allowing verification without revealing underlying data.

Gas Optimization

Techniques to reduce computational costs of executing transactions on Ethereum-compatible networks.

PoS

Proof of Stake consensus where validators are selected based on their cryptocurrency holdings.

51% Attack

Attack scenario where a single entity controls majority of network's mining/validation power.

Ethereum Merge

Transition from Proof-of-Work to Proof-of-Stake consensus in Ethereum.

Cryptography

Mathematical techniques for securing information and communications in blockchain systems.

Cross-Chain Bridge

Infrastructure enabling asset transfers between different blockchain networks.

Smart Contracts

Self-executing digital agreements with terms directly written into code.

EVM

Ethereum Virtual Machine that executes smart contracts in the Ethereum network.

Gas

Unit measuring computational effort required to execute operations on Ethereum.

DeFi

Decentralized Finance applications offering financial services without traditional intermediaries.

DAO

Decentralized Autonomous Organization governed by code and community voting.

ENS

Ethereum Name Service mapping human-readable names to blockchain addresses and resources.

NFT

Non-Fungible Token representing unique digital assets with provable ownership.

Ethereum

Blockchain platform enabling smart contracts and decentralized applications.

DPoS

Delegated Proof of Stake consensus where token holders elect validators to secure the network.

PoA

Proof of Authority consensus relying on approved validators with known identities.

Optimistic Rollups

Layer 2 scaling solution assuming transactions are valid by default with fraud proof security.

ZK Rollups

Layer 2 scaling solution using zero-knowledge proofs to verify transaction validity.

ERC-20

Token standard for fungible tokens on Ethereum, enabling interoperability across applications.

Bitcoin and Blockchain

The original cryptocurrency and its underlying technology, revolutionizing digital finance.
