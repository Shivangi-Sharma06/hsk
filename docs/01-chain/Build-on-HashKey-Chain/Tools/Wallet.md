Connect to HSKChain with popular wallets

### Manual Setup: Adding HSKChain to OKX Wallet

If the one-click button doesn't work for your device, follow these manual steps to add HSKChain to your OKX Wallet:

#### 1. Open OKX Wallet application

Launch the OKX Wallet desktop or mobile application, or activate the browser extension.

#### 2. Navigate to network settings

Tap on the network selector at the top of the screen, then select "Add Custom Network" or "Add Network" at the bottom of the networks list.

#### 3. Enter HSKChain network details

Fill in the following network parameters:

| Parameter | Value |
| --- | --- |
| Network Name | `HSKChain` |
| RPC URL | `https://mainnet.hsk.xyz` |
| Chain ID | `177` |
| Currency Symbol | `HSK` |
| Block Explorer URL | `https://hashkey.blockscout.com` |

#### 4. Save and connect

Tap "Save" or "Add" to confirm. The wallet will validate the connection and add HSKChain to your networks list. You can now select HSKChain from your networks dropdown to start interacting with the blockchain.

> **Pro Tip:** After adding HSKChain to your wallet, you can easily switch between networks by selecting HSKChain from the network dropdown menu. This allows you to manage assets and interact with dApps across multiple blockchains seamlessly.

## Other Compatible Wallets

In addition to OKX Wallet, HSKChain is compatible with several other popular EVM-compatible wallets:

* **MetaMask**
* **TokenPocket**
* **ImToken**

The network parameters remain the same for all wallets.
